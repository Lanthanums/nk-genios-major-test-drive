# 理工与信息专业知识研究交付

读取日期：2026-10-17。已产出 `stem_catalog.json`（18个专业）和 `stem_sources.json`（18个中文高校官方来源）。

专业覆盖计算机科学与技术、物联网工程、信息安全、自动化、智能科学与技术、软件工程、物理学、应用物理学、光电信息科学与工程、电子信息科学与技术、微电子科学与工程、电子科学与技术、通信工程、数学与应用数学、信息与计算科学、统计学、数据科学、量子信息科学。专业名称严格保留用户目录。

每卡包含通俗简介、一个原创三步工作情景、三个原创入门活动、基础知识类别、常见误解、相近专业比较、两个可用于原创出题的概念与计算/表述边界、来源ID和适用限制。所有工作情景均标为概念化教学例子，不称为真实高校作业、实习任务或岗位实录。

专业介绍是自写短摘要；典型工作、比较、题目概念为基于来源的教学转述或创作。来源只支持专业基本对象与方向，不能据此证明任意一道新题等同完整专业学习，更不能把答题分数变成适配度或能力排名。

## 整合建议

1. 专业问答应先读大类目录核范围，再检索完整专业名称的知识卡。跨类兴趣仍可介绍，但资格不能从通识来源推断。
2. 对比专业时给“同一问题中不同关注点”，并保留交叉与校际差别；不要使用“统计只理论、数据只应用”等二分。
3. 出题使用卡内 `question_concepts`，同时遵守边界，所有参数另标为原创合成。当前卡不提供真实设备、电路、量子装置操作指导。
4. 特色班可展示基础专业通识，但必须另行补特色培养材料，不能把普通专业卡当已核验特色班课表。
5. 保留具体URL、发布日期与读取状态。无正文日期的页面写 `null`；方案版本、URL路径日期和搜索引擎爬取日期不能冒充发布日期。
