# v2.2.0 部署清单（2026-10-17）

## 修订 1（2026-10-17 晚）：首轮实测问题修复

针对实测反馈的修复，**四个工作流和 Agent 提示词都需要重新导入/粘贴**：

1. **按钮页自由文本**：探针 WF_Probe_OptionText 实测确认——平台按钮页的 Others 分支**不暴露用户原文**，无法把按钮页打的话接回流程，故维持 v2.1 行为（按钮页打字会保留已有记录并友好结束）。改为在 Agent 提示词中规定了补救话术：说明刚才的输入没有被计算、可以重新开始一次该活动，不伪装成方案已提交。探针文件保留在 `platform_import/WF_Probe_OptionText.yaml` 供存档，**无需导入**。
2. **知识问答引用校验容错**：模型逐字引用时允许空白/换行差异；提示词强调逐字复制，减少“还需核对”的出现。
3. **Agent 不再向学生转述内部校验状态**（“引用核对没有通过”等），回答先直给、不说教、不罗列无关专业。

## 本版改了什么

1. **报告新增“下一步建议”章节**（引擎 2.2.0）：每次体验报告末尾会依据本次实际完成的内容，给出相关专业方向（并按大类内/跨类区分）、建议再体验的活动类型、以及可继续追问的问题句式。建议带依据与边界声明，不是分数或排名。
2. **知识库 33 张专业卡全部增补**：每张卡新增「本科常学课程」「常见实验与实践环节」「毕业去向方向」三段及来源（v2.2.0 增补，以南开大学官方页面为主，少量注明为转载或外校参照）。`00_scope`、`05_faq`、`09_how_to_choose` 同步更新边界表述；FAQ 新增“系统会直接告诉我选哪个专业吗”“我只试了不到 3 次就想离开，会怎样”两条。
3. **知识问答提示词 v2.2.0**（`resource_answer.md`，已内嵌进 WF_Major_Knowledge_v2）：默认语境为南开大学大一新生，不再索要“所在学校”；允许给出有依据的倾向性建议；missing 字段改为指出具体缺项。
4. **主 Agent 提示词 v2.2**：新增“结束与挽留”规则（完成体验不足 3 次且未挽留过时挽留一次）；明确允许并规范“给建议”的行为；知识问答段落更新。
5. **生成器修复**：空字符串常量输入不再生成（上轮“参数配置不合法”的根因），今后重建不会回潮。

## 部署顺序

### 第 1 步：知识库
- 上传 `knowledge_base_upload.zip`（65 个 md，约 102 KB）。
- 若平台是追加式导入，请先清空 KB_NK_Explore 的旧文档再整体重传，避免新旧两版并存导致检索混乱。

### 第 2 步：工作流（4 个，全部在 `platform_import/`，修订 1 后全部需重新导入）
1. `WF_Major_Knowledge_v2.yaml`（34,169 B）
2. `WF_KB_Practice_Draft_v2.yaml`（33,110 B）
3. `WF_Explore_One_v2.yaml`（1,793,712 B）
4. `WF_Explore_One_v2_Offline.yaml`（1,763,336 B）

导入后逐个打开，确认知识检索节点绑定的仍是 KB_NK_Explore；旧版同名工作流建议下架或删除，避免 Agent @ 错版本。

### 第 3 步：Agent 提示词
- 用 `prompts/agent_system_at.md` 全文替换现有人设与回复逻辑。
- 粘贴后逐个把 `@WF_Explore_One_v2`、`@WF_Major_Knowledge_v2`、`@KB_NK_Explore`、`@WF_KB_Practice_Draft_v2` 用编辑器的 @ 选择器重新选一遍，变成真正的资源引用，然后删除文末“维护者挂载说明”一段。

### 第 4 步：开场白（平台 Agent 的“开场白/对话建议”配置）

开场白正文：

> 你好，我是专业试驾场助手，为南开大学大一新生的大类分流提供参考。我可以陪你做三件事：
>
> 1. **专业试驾体验**：从 9 类动手小活动里选一个，试一个方案、看看条件变化后的结果，最后留下一份你自己核对过的探索记录；
> 2. **专业问答**：问我任何专业“平时学什么课、做什么实验、毕业去向有哪些”，或比较两个专业有什么区别；
> 3. **下一步建议**：体验结束后，我会根据你实际做过的内容，建议接下来重点了解的专业和活动。
>
> 随时可以说“结束并给我报告”。想开始的话，直接说“我想体验一下”，或问我一个专业问题。

推荐快捷提问（若平台支持）：
- 我想体验一下
- 计算机科学与技术和软件工程有什么区别？
- 数学与大数据类里有哪些专业方向？

### 第 5 步：验收测试
1. 完整跑一轮任一体验 → 报告末尾应出现“## 下一步建议”章节，列出与大类匹配的相关专业。
2. 追问“计算机科学与技术和软件工程有什么区别？” → 回答应引用新版知识卡的课程/实验/去向内容，不再出现“缺少你所在学校的培养方案”。
3. 只完成 1 次体验就说“我先走了” → 应收到一次挽留（建议再试一两类）；再次表示离开 → 正常给记录，不再挽留。（挽留由提示词约束，属模型行为，若偶发不触发可再强调规则。）
4. 结束前确认平台上遗留的探针工作流（Probe A2/B2/B3/D/E 等）已删除。
