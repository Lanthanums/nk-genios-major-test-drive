# 价值排序：三个可选情境

题面、两阶段条件和确定性规则以config/case_bank.json为准；本文件为阅读索引。

## 教授的走廊（values_research_day）
合成老教授用"哪几天下班是哼着歌的"回答"这行图什么"，八张卡片各是一种科研工作里的真实快感。
阶段0：把卡片从"最不能少"排到"最无所谓"，说说顺序和理由。
阶段1：教授追加条件——入行头五年排在最后两名的东西都拿不到，重新排一次并解释变化。
边界：不评估价值观优劣；教授为合成人物。

## 辅导员的统计表（values_offer_letter）
合成匿名统计显示上一届"大一意向"与"最终落点"重合率不到一半，卡片是毕业去向里可以看重的八种东西。
阶段0：把卡片从"对我最重要"排到"最无所谓"。
阶段1：家里突然经济紧张、头三年每月需往家寄钱，条件变了重新排，两次排序的差距本身就是答案。
边界：不做职业规划建议；统计数据与情境均为合成。

## 不许碰的那件事（values_team_role）
合成软件工程课自由组队，老师提醒"每年挂掉的是四个人都想当架构师的队"，卡片是团队里最忍不住要管的事。
阶段0：把卡片从"最忍不住"排到"随它去"。
阶段1：老师规定你排第一的那件事这学期由别人全权负责、你不许碰，重排剩下的并说说打算怎么活。
边界：不评估领导力或性格类型；课程情境为合成。
