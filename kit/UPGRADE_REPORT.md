# 专业试驾场 v2.1.0 修复报告

本轮依据2026-10-17实际试用反馈修复交互和流程衔接。保留9类27个情境、65份学生知识资料、36条来源记录和既有大类成员清单；没有重新联网核验或扩大学科知识覆盖。

## 已修复的行为

| 试用问题 | 当前处理 |
| --- | --- |
| Agent外层选题、工作流内重新问背景，职责重叠 | Agent收到体验意图直接调用；新增 `reported_group_text`，本人已明确且唯一对应的大类直接复用，未知/歧义才问一次 |
| 所有内容挤在一起，原话后硬接句号 | 长文本使用Markdown标题、段落、粗体与斜体说明；原话独立引用并转义，保留原标点，后台存储原文 |
| 两次后想直接拿报告，却进入错误或继续追问 | 每个可回答阶段提供结束入口；明确自然结束优先处理，直接返回已有事实，不要求反思或整份记录确认 |
| 明明有按钮却要求输入编号 | 大类、活动情境、选择方案、确认和结束采用信息收集选项分支；修改先点“我想改一下”，再进入直接回答页 |
| 用户看见内部参数和生硬指令 | 内部默认值、状态、JSON、案例编号保留在机器字段；学生界面展示通俗说明和当前阶段 |
| 其他复核问题 | 控制题补齐初值、目标、步数及每步更新规则；记录确认与方案确认分开；含“结束”的引用、否定、假设和普通说明不自动当退出 |

用户给出的模型调试片段能够证明入口职责需要收紧，但未完整展示工作流调用参数与节点轨迹，不能仅凭这段数据断言重复大类的唯一精确节点原因。本轮同时修复主 Agent 合同与工作流的大类复用、按钮和单次收集路径。

## 报告现在怎样说明完成情况

报告只把经过本人明确确认的方案列为正式试算事实。条件变化后的旧方案复算会单列；未确认的新方案保存为“已提出、还没确认”，没有计算结果。提前结束时，没有完成的阶段不会写成已完成；没有反思就写未填写；反思有原话但未确认整份记录时，也明确其确认状态。

结束是正常分支，不意味着学生能力不足、兴趣不足或做错。再次请求同一已结束记录不会重复计算或追加伪造事实。出错时尽量返回操作前的有效状态和已有报告，面向学生说明如何继续；诊断细节留在后台字段。

## 本轮本地证据

运行层12项回归测试通过，覆盖27个情境的8个有效生命周期状态、7种结束入口，共1512次结束重放；另核对9个v1.1旧数值快照，计算结果保持一致。此数量是本地确定性夹具的调用次数，不是独立学生人数、平台会话数或测量有效性证据。

两份新增完整案例由当前代码生成题面、预览、反馈与报告。双方语言、入口选择和模型候选为显式模拟；没有把假定检索命中写成真实召回。

完整本地测试共59项通过。独立执行交付的两份体验 YAML 共152条检查/路径全部通过，包含27情境各两版本的完整两阶段路径、大类复用、全部可达按钮及其他分支、自然语言结束和报告保留。另执行两份知识工作流验证有命中、无命中和草稿拒绝；模型与检索均为显式夹具。实际证据见 `tests/local_test_result.txt`、`tests/workflow_verification.json`。v2.0报告中的38项测试、46条独立路径和重建哈希属于历史证据，不能代替v2.1验证。最终打包时应重新生成当前manifest和压缩包校验值。

## 内容与部署边界

本次仅更新知识卡 `00_scope.md` 与 `05_faq.md` 的交互说明，专业事实、成员清单和来源登记保持原样；不能把包版本升级当成重新核验来源。65份资料包含33个专业介绍、7组相近专业比较、3张计量概念卡，以及活动、大类、政策和使用说明。已上传v2.0资料者替换两张说明卡并等索引，其余63份无需重传。36条来源记录不等于完整个人年级课表，也不直接证明某个学生符合跨类、辅修或转专业资格。

专业问答与开放练习的来源检查规则保持不变，展示层增加段落和独立引文。出处存在性检查不等于回答或题目通过学科审核；开放练习仍不自动入固定题库、不评分。固定选择题的理由也没有新增质量评分。

主体验真实工具名仍为 `WF_Explore_One_v2`，入口新增必填字符串 `reported_group_text`，空串表示没有已明确的大类信息。更新YAML后必须更新主 Agent 提示词和工具schema；不能同时挂载同名新旧流程，让模型随机选用。

本轮没有登录、导入或发布平台。租户侧按钮展示、其他分支、Markdown渲染、工具暂停续答、真实模型提取、知识库召回、超时和用户隔离仍待验收。平台自动追加的强制摘要规则若会改写报告，应由维护者调整；模型不能用摘要替代原始事实报告。

当前样例没有证实选项节点“其他”分支可读取自由输入原文，因此该分支保守结束并返回已有记录，而不猜测输入内容。自然修改需先点“我想改一下”，然后在直接回答页填写；直接回答页接受明确自然结束请求。这个限制不能说成已经支持任意按钮页文字聊天。

调试数据里的主 Agent 回复上限为1024 tokens，完整报告可能超过它。若外层模型重述工具报告，会出现截断或改格式风险。平台应尽量让工作流原报告直接展示；确需模型承接时，将回复上限设为4096或模型支持的更高值并实测。此项是外层平台设置，YAML导入不能自动修改。旧知识工具简介中的“三类体验”也需改为九类，或移除旧工具避免重复调用。

`skills/` 是本项目可粘贴的教学角色说明，不是已验证的Skill导入格式，也没有安装到本机Codex技能目录。旧版完整备份与历史审查材料应保留，不覆盖成“本轮已验证”。
